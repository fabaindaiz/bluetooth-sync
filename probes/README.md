# Probes

Scripts desechables para los experimentos de la Fase 1 (`docs/roadmap.md`).

- Cada probe va en una subcarpeta con su nombre.
- Cuando su resultado está anotado en `docs/research/experimentos/`, **se borra**
  (d-7c8794-3208b7), **salvo que sea la fuente de una cifra anotada**: en ese caso queda,
  para poder volver a medir con lo mismo, y el experimento lo cita (usuario, 2026-10-09; por
  ejemplo `probes/20-costo-sinc-rust/`, fuente de `experimentos/20` §8–§10).
