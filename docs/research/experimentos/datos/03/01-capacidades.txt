===== 1. LE Features del controlador (la lectura que decide) =====
 0: bf fe 0f fe db ff 7b 87
 1: 0b 00 00 00 00 00 00 00
 2: 20 0b 00 00 00 00 00 00
LE: ff 59 01 3c ae 00 00 00

LE Features: 0xff 0x59 0x01 0x3c 0xae 0x00 0x00 0x00

== Los que deciden algo en este proyecto ==
  [SI ] bit 28  Connected Isochronous Stream - Central
           → unicast LE Audio (Tune 770NC)
  [SI ] bit 29  Connected Isochronous Stream - Peripheral
  [NO ] bit 30  Isochronous Broadcaster
           → EL BIT QUE DECIDE E1: crear un BIG
  [NO ] bit 31  Synchronized Receiver
           → recibir un BIS (leer el BIGInfo en E2)
  [NO ] bit 13  LE Periodic Advertising
           → hace falta para leer la BASE (E2)
  [SI ] bit 12  LE Extended Advertising
           → requisito de radio para Auracast

VEREDICTO: el controlador NO declara Isochronous Broadcaster (bit 30).
           No puede crear un BIG. E1 pasa a las SuperMini nRF52840
           (d-7c8794-b82ee9) o a una tarjeta MT7921/BE200.

===== Resumen =====
Si el bit 30 (Isochronous Broadcaster) está en NO, este chip no transmite y
E1 pasa a las SuperMini. Si el bit 28 (CIS Central) está en SI, se puede
probar unicast LE Audio con los Tune 770NC, que sí exponen PACS y ASCS
(experimentos/02-servicios-de-los-jbl-linux.md).
